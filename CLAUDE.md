# Project Context for AI Assistants

## Overview
This repository extracts, structures, and analyzes "Tony's Diary" — a 1,141-page personal journal by Dr. Anthony Fauci (NIAID Director, Jan 2020–Dec 2022), released by Chairman Rand Paul (U.S. Senate Homeland Security Committee) in July 2026. The analysis focuses on Dutch institutional involvement and lab-origin discussions in early COVID-19 origins research.

## Key Files
- `src/parse_all_docs.py` — Main ingestion pipeline: reads PDF text, targets ~20 persons + ~15 organizations, writes SQLite
- `src/auto_downloader.py` — External data: NIH RePORTER (grants), OpenAlex (publications), FOIA references
- `src/export_graph.py` — NetworkX export + dossier generation
- `data/raw_data.json` — 1,141 page-wise text extractions (gitignored, regenerated by `src/extract_pdf.py`)
- `data/network_data.db` — SQLite: nodes, edges, evidence_quotes, financial_grants, timeline (gitignored)

## Methodology
- **Entity extraction**: Case-insensitive regex matching against curated target list (no ML NER — intentional to avoid hallucination)
- **Evidence traceability**: Every quote includes `page` field linking to source page in PDF
- **Blind spots explicitly documented**: `docs/BLIND_SPOT_MAPPING.md`

## Known Limitations
1. Diary is Fauci's personal narrative — NOT an email archive. References to "Koopmans' Feb 9 email" are from FOIA releases, not this document
2. No ML-based NER — false positives in co-author detection were systematically removed
3. SSL certificate issues on corporate networks may block NIH RePORTER API — see `src/auto_downloader.py` ssl_ctx bypass
4. Dutch entities found: Fouchier, Koopmans only. Ab Osterhaus not found in diary

## Pipeline Order
1. `src/extract_pdf.py` → raw_data.json (requires PDF)
2. `src/auto_downloader.py` → data/downloads/*.json
3. `src/parse_all_docs.py` → network_data.db
4. `src/export_graph.py` → graph.json + DUTCH_CONNECTIONS_DOSSIER.md
